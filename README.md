# Chess Engine

A Python-based chess game and engine built with Pygame.

## Features

- Interactive GUI powered by Pygame
- Move generation and legal move validation (including checks, checkmate, stalemate, and promotions)
- Position evaluation and search algorithm
- Graphical chess piece assets

## Requirements

- Python 3.8+
- [Pygame](https://www.pygame.org/)

## Installation & Running

1. Clone the repository:
   ```bash
   git clone https://github.com/jihadv4/chess-engine.git
   cd chess-engine
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the game:
   ```bash
   python game.py
   ```
